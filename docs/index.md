# Latticer Time documentation

Latticer Time is a small, self-hosted timer for solo consultants and freelancers. It logs your hours into **your own Airtable base** and tells you when a retainer's included hours are running out.

This page helps you find the right guide. If you are not sure the tool is for you, start with [Who it is for](who-its-for.md).

## How these docs are organized

The docs follow four kinds of need, kept apart on purpose so each page does one job:

- **Learn:** [Who it is for](who-its-for.md), [Why it works this way](why-it-works-this-way.md), [Case study](case-study.md).
- **Do a task:** [Setup guide](setup.md), [User guide](user-guide.md), [Customizing](customizing.md).
- **Look something up:** [Airtable schema](airtable-schema.md), [Changelog](changelog.md), [Schema changelog](schema-changelog.md).
- **Fix a problem:** [Troubleshooting](troubleshooting.md), [Security notes](security.md).

## Keeping the docs current

Every feature release gets a [changelog](changelog.md) entry, and every Airtable change gets a [schema changelog](schema-changelog.md) entry plus an update to the [schema reference](airtable-schema.md). The checklist is in [CONTRIBUTING.md](../CONTRIBUTING.md).
